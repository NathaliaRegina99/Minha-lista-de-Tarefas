# Feature: Minha Lista de Tarefas

## Objetivo

Desenvolver uma aplicação web para permitir que o usuário organize suas tarefas diárias de forma simples e prática.

## Funcionalidades

### Cadastrar tarefas

O usuário poderá cadastrar uma tarefa informando:
- Título da tarefa.
- Descrição (opcional).
- Prioridade (Baixa, Média ou Alta).

### Listar tarefas

O sistema deverá apresentar todas as tarefas cadastradas, mostrando título, descrição, prioridade e status.

### Concluir tarefas

O usuário poderá marcar uma tarefa como Concluída ou voltar para Pendente.

### Excluir tarefas

O usuário poderá excluir tarefas cadastradas mediante confirmação.

## Dados da tarefa

Cada tarefa deverá possuir:
- ID único.
- Título.
- Descrição.
- Prioridade.
- Status.

## Armazenamento

As tarefas serão armazenadas no LocalStorage do navegador.

## Interface

- Layout simples e intuitivo.
- Design responsivo.
- Utilização do Bootstrap 5.3.
- Cores agradáveis e boa organização visual.
